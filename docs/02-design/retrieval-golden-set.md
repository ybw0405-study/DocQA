# 检索黄金集：可溯源语料与表述鲁棒性

## 目的

现有 [retrieval-eval.md](retrieval-eval.md) 的 21 题标注集混合了合成语料与真实条文，主要服务于离线链路回归。本黄金集补的是另一件事：**每条查询都能追溯到具体法规条款，并系统观察同一事实在不同表述下的召回稳定性**。它不替换原基线，`--check-baseline` 门禁不受影响。

数据文件：[`ai-python/src/docqa_ai/eval/golden_set.json`](../../ai-python/src/docqa_ai/eval/golden_set.json)
实现：[`ai-python/src/docqa_ai/eval/golden.py`](../../ai-python/src/docqa_ai/eval/golden.py)

## 语料与来源

候选池取 `corpus.py` 中 `document_id = real-legal` 的 8 个条文块，逐块标注法规与条款：

| 块 | 来源 | 主题 |
|---|---|---|
| 0 | 《劳动合同法》第四十七条 | 经济补偿按工作年限折算 |
| 1 | 《民法典》第一千零六十四条 | 夫妻共同债务的认定 |
| 2 | 《个人所得税法》综合所得税率条款 | 3%–45% 超额累进税率 |
| 3 | 《道路交通安全法》第九十一条第一款 | 饮酒驾驶处罚 |
| 4 | 《劳动合同法》第八十七条 | 违法解除的二倍赔偿金 |
| 5 | 《道路交通安全法》第九十一条第二款 | 醉酒驾驶处罚 |
| 6 | 《民法典》第一千零八十九条 | 离婚时共同债务清偿 |
| 7 | 《个人所得税法》第六条 | 综合所得六万元减除费用 |

条文为公开法律法规的节选片段，内容可人工复核；未引入语料之外的事实。

## 查询设计

每个条文块构造 4 条查询，共 32 条正例；另加 5 条语料无答案的负例。变体类型：

| 变体 | 说明 | 条数 |
|---|---|---|
| 原文问法 | 沿用原有标注集的问法 | 8 |
| 口语化 | 用日常说法描述同一事实 | 8 |
| 术语替换 | 换用法律/税务术语 | 6 |
| 部分信息 | 只给条款里的一个细节反查 | 6 |
| 反向问法 | 从结论反推适用条款 | 3 |
| 易混淆对照 | 故意与相邻条款词面重叠 | 3 |

负例覆盖工伤保险、专利、公积金、商标、不动产登记，均不在语料范围内。

## 评测口径

- 离线确定性特征哈希向量（`OfflineEmbeddingProvider`，1024 维），**不是语义检索**；零外呼、零成本、任意机器可复现。
- 检索为「问句编码 → 与 8 个候选块余弦打分 → 取 top5」，不启用 rerank、不启用词法通道。
- 指标：recall@1 / @3 / @5、MRR、按变体分组的 recall@1；负例报告 top_score 均值与误召回率（阈值 0.35）。

复现：

```bash
cd ai-python
python -m docqa_ai.eval.golden
python -m docqa_ai.eval.golden --report /tmp/golden-report.json
```

## 实测结果（2026-11-25，本机离线）

| 指标 | 数值 |
|---|---|
| 正例 / 负例 | 32 / 5 |
| recall@1 | 0.9375 |
| recall@3 / @5 | 1.0 / 1.0 |
| MRR | 0.9688 |
| 负例平均 top_score | 0.1468 |
| 负例误召回率 | 0.0 |

按变体的 recall@1：

| 变体 | recall@1 |
|---|---|
| 反向问法 | 1.0 |
| 口语化 | 1.0 |
| 术语替换 | 1.0 |
| 部分信息 | 1.0 |
| 原文问法 | 0.875 |
| **易混淆对照** | **0.5** |

**主要发现**：词面高度重叠的相邻条款是当前检索的最弱环节。典型是把「吊销驾驶证并约束至酒醒适用于饮酒还是醉酒」「夫妻共同债务在离婚时由一方承担还是共同偿还」这类问法打到相邻块上——两块共享大量字词，特征哈希向量区分度不足。这不是随机噪声，而是可复现的系统性弱点，改进方向是引入语义 embedding 或 rerank 后按同一黄金集复测对照。

## 局限

- 32 条正例、8 个候选块，样本量小且集中在四个法律主题，**不能证明跨域泛化能力**。
- 离线特征哈希不是语义模型；本结果只代表「词面 + 哈希」通道，切换真 embedding 后需重建对照表。
- 候选池是单文档内的 8 块，不含跨文档干扰文档；跨文档 hard negative 仍由原 21 题标注集覆盖。
- 没有接入 LLM 生成与引用核对，本集只评检索，不评 faithfulness。
